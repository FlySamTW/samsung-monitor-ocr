# Samsung OCR 系統技術參考手冊 (Technical Reference)

本文件整合了系統的核心邏輯、開發演進歷程以及維護規則，是系統開發與除錯的唯一權威指南。

---

## 1. 核心辨識邏輯 (Core Logic v18.22)

### **A. 零記憶辨識律 (Zero Memory Policy)**

- **獨立性**：每一張照片都是一個獨立事件。系統在處理新照片前會強制清除對話歷史。
- **防止幻覺**：AI 禁止參考上一張的結果，必須以全新視角判讀目前照片。

### **B. 盤點式推理 (Inventory Reasoning)**

- **強制盤點**：AI 必須先列出畫面上所有看到的 S... 字串與價格數字，才允許進行邏輯判定。
- **證據對應**：輸出結果必須有盤點中的碎片作為依據，禁止「無中生有」。

### **C. 空間與尺寸雙重鎖定 (Spatial & Size Guard)**

- **垂直投影規則**：價牌的正中心必須落在主體螢幕支架/底座的水平寬度範圍內。
- **尺寸核對**：若螢幕標識 27 吋，價牌寫 32 吋，系統判定為「誤配」並強制定為 null。

### **D. 型號規律校驗 (Model Pattern Match)**

- **格式規範**：型號必須符合三星特徵前綴 (S/C/F/U/LS/WA)。
- **黑名單**：禁止輸出「SAMSUNG」、「27吋」等描述關鍵字作為型號。
- **標籤優先**：強制鎖定「機型 :」標籤右側字串。

## 2. 開發歷程 (Version History)

### **v18.21 - v18.22**: 精準度與獨立性強化

- **v18.22**: 強制落實「零記憶辨識律」，確保無上下文干擾。
- **v18.21**: 定義合法型號規律模式，鎖定「機型 :」標籤，解決 302 描述性文字誤導問題。

### **v18.10 - v18.19**: 防腦補與對齊規則演進

- **v18.19**: 實作「盤點式推理」，明確負面示例解決 852/302 頑固錯誤。
- **v18.18**: 實作「空間垂直投影」與「尺寸核對」機制。
- **v18.17**: 嚴禁腦補 `S27CG552EC`；引入標籤優先權。
- **v18.16**: 嚴禁將 G74 等代號視為型號。設定「粉紅/彩色貼紙」為最高資訊權利。

### **v18.01 - v18.15**: 架構基礎與 FollowMe 支援

- **v18.15**: 實作 FollowMe 價格區間自動映射機制。
- **v18.10**: 品牌防禦 (Brand Guard)，排除 Switch/Asus 等非三星主體。
- **v18.05**: 引入 Python 後端 Fuzzy Match (Cutoff 0.8) 進行模糊修復。
- **v18.01**: 建立底座定錨原則，強制定義價格為 4-5 位純數字。

## 3. 實戰經驗庫 (Learned Experience)

### **特定案例處理 (Few-Shot Experience)**

- **遠景判定**：當畫面上超過 3 台完整螢幕且無近處價牌時，歸類為「遠景」。
- **螢幕狀態**：黑屏或藍屏應標註為「不合格」。
- **代碼禁令**：Odyssey 是系列名稱，G74 是代號，均不可取代 S27... 正式型號。

---

## 4. 維護規則 (Maintenance Rules)

- **語言要求**：系統對外輸出與內部思考過程必須統一使用 **台灣繁體中文**。
- **數據完整性**：若看到價牌但不可讀，類別應標為 `不合格-照不清楚`。
- **備份機制**：每次重大 Prompt 更新後，應更新儀表板版本號以便追蹤。
