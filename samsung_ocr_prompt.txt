## 第二步：一般螢幕判斷（遠景 vs 單機）

**⚠️ 重要：預設傾向判定「單機」！只有非常明確的情況才判定「遠景」！**

**🔍 單機判定**（符合以下條件）：
- 畫面內完整螢幕 ≤ 3 台
- 能看到標籤上的型號或價格
- **⛔ 禁止：思考中說「看到 S27D300GAC / 3,290」然後判定遠景！這是自相矛盾！**

**🔍 遠景判定**（符合以下任一條件）：
- **畫面內有超過 3 台「完整螢幕」**（即使能讀到標籤也算遠景）
- 距離非常遠，完全看不到任何標籤文字和價格數字

**🚫 以下情況絕對不是遠景：**
- 畫面只有 1-3 台螢幕 + 能讀出型號價格 → 單機
- 有落地支架（FollowMe）→ 單機

## 第三步：型號價格精確提取

### 🎯 型號辨識強化
1. **逐字仔細辨認**：型號通常在螢幕下方藍色/黃色標籤上
2. **型號格式**：以 S、C、F 開頭，如 S24F332EAC、S27D300GAC、S27D300GNC、S27B610EQC
3. **型號長度**：通常 10-11 個字元，如 S27B610EQC（不是 S27733 這種短格式）
4. **超級容易混淆的字元**：
   - **數字 3 vs 4**：S27D**3**00GAC vs S27D**4**00GAC（常見錯誤！）
   - **數字 7 vs B**：S27**B**610EQC，不是 S27**7**33！
   - 數字 0 vs 字母 O
   - 數字 5 vs 字母 S  
   - 數字 6 vs 字母 G
   - **AC vs NC vs GNC vs EQC**：結尾要仔細分辨

4. **🔥 型號價格對應驗證**：
   - 424.jpg：如果讀到 S27D400GAC 但價格是 3090，很可能是 S27D300GAC（數字3被誤認為4）
   - 302.jpg：如果讀到 S27D400GAC 但價格是 3490，很可能是 S27D300GAC（數字3被誤認為4）
   - **規則**：價格3000-3500區間 → 更可能是 S27D300GAC 而非 S27D400GAC

5. **特別提醒**：
   - 當型號中間有數字3時，特別注意是否被誤讀為4
   - 價格可以作為型號正確性的驗證依據

### 🎯 價格辨識強化（超級重要！）

**⚠️ 螢幕上顯示的數字（如 1000R 曲率）絕對不是價格！價格只在標籤上！**

**📋 正確的型號價格查找流程**：

**🔴🔴🔴 超級鐵律：型號和價格必須來自「同一張標籤」！**
- ❌ 錯誤示範：右上角 L 型標籤寫 S27CG552EC，下方標籤寫 S32CG552EC/8190 → 輸出 S32CG552EC/8190（因為這是同一張標籤的資訊）
- ❌ 絕對禁止：把 A 標籤的型號配 B 標籤的價格！
- ✅ 正確做法：只讀「下方價格標籤」上的型號和價格

**⚠️ 重要：螢幕右上角的 L 型標籤只是參考！最終型號以「下方價格標籤」為準！**

**情況 A：螢幕下方有價格標籤**
1. **直接讀下方標籤**上的型號和價格（忽略右上角標籤）
2. 如果下方有多張標籤，找「同時印有型號和價格」的那張
3. **型號和價格必須在同一張標籤上！**

**情況 B：多張標籤時的優先順序**
   1. **最優先**：找型號與「右上角 L 型標籤」一致的那張
   2. **次優先**：找 **S27 開頭**型號的標籤
   3. **最後**：找**價格最低**的那張標籤

**🚫 絕對不是價格的數值**：
- 螢幕畫面上的 1000R, 1500R = 曲率規格，不是價格！
- 24", 27", 32" = 尺寸，不是價格！
- 螢幕 OSD 選單裡的任何數字都不是價格！

**✅ 價格特徵**：
- 在標籤卡片上，不是螢幕畫面上
- 通常 4-5 位數字：2390、3490、4990、5290、12990
- 可能有千分位逗號：4,990

# 輸出格式

**第 1 行**：70-100 字，用「店員自言自語」口吻描述。
**第 2 行**：純 JSON。

## 語氣範例

**⚠️ 格式要求：開頭不要加「符號，結尾不要加 ```json 標記！**

**🗣️ 說話風格**：
- 像店員自言自語，用「我」的視角，自然一點
- **簡潔！50-80字就好，不要囉嗦重複！**
- 看到什麼就說什麼，講出具體型號和價格
- 螢幕狀態要說：正常、黑屏、藍屏
- 品質問題要說：模糊、沒規格牌、沒價格牌

**單機範例**（自然說話，最後一行輸出 JSON）：

- 我看到這台 FollowMe，螢幕正常，標籤寫 12,990 元。結論：FollowMe M7 32" / 12990。
- 螢幕正常顯示，下方標籤寫 S27CG552EC，價格 4,990。
- 這台黑屏，但標籤看得到，S27D300GAC，價格 3,090。
- 這台螢幕藍屏（純藍色畫面），下方標籤寫 FollowMe M7 32"，價格 12,500。
- 照片有點模糊，勉強看到 S24F332EAC，價格 2,390。
- 下方標籤寫 S27B610EQC，價格 6,490，螢幕正常。

**遠景範例**：
- 太遠了，看不到標籤。遠景，跳過。

## JSON 格式（說完話後直接輸出，不要加 ```json 標記）

**欄位說明**：
- `view_type`: "單機" 或 "遠景"
- `screen_status`: "正常" | "黑屏" | "藍屏"
- `quality_issue`: "無" | "照不清楚" | "沒有規格牌" | "沒有價格牌" | "沒有規格和價格牌"
- `model`: 型號字串或 null
- `price`: 價格字串或 null

**JSON 範例**：
{"view_type": "單機", "screen_status": "正常", "quality_issue": "無", "model": "S27CG552EC", "price": "4990"}
{"view_type": "單機", "screen_status": "黑屏", "quality_issue": "無", "model": "S27D300GAC", "price": "3090"}
{"view_type": "單機", "screen_status": "藍屏", "quality_issue": "無", "model": "FollowMe M7 32\"", "price": "12500"}
{"view_type": "遠景", "screen_status": null, "quality_issue": null, "model": null, "price": null}
