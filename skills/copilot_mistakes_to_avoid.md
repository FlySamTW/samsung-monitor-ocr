# 第二部分：Qwen3-VL OCR 最佳實踐

## 1. 模型參數設定

| 參數               | 官方建議 | OCR 任務優化 | 說明                                   |
| ------------------ | -------- | ------------ | -------------------------------------- |
| `temperature`      | 0.7      | **0.1**      | OCR 需要精確讀取，必須用低溫度避免幻覺 |
| `top_p`            | 0.8      | 0.8          | 保持官方建議                           |
| `top_k`            | 20       | 20           | 保持官方建議                           |
| `presence_penalty` | 1.5      | 1.5          | 避免重複輸出                           |
| `max_tokens`       | -        | 512          | OCR 任務不需要太長輸出                 |

### 關鍵發現

- temperature=0.7 會導致價格幻覺（13,291 → 13.29）
- temperature=0.1 可達到 100%（5/5）正確率

## 2. 圖片處理原則

### ❌ 錯誤做法：重新編碼

```python
# 這會損失畫質！
img.convert("RGB").save(buffered, format="JPEG", quality=90)
```

### ✅ 正確做法：直接讀取原始 bytes

```python
with open(image_path, 'rb') as f:
    img_b64 = base64.b64encode(f.read()).decode()
```

## 3. Few-shot 範例的陷阱

❌ **致命錯誤：範例中包含具體價格數字**

```
這台是 FollowMe，標籤寫 12,900
```

模型會學到「FollowMe = 12,900」的錯誤關聯！

✅ **正確做法：使用佔位符**

```
這台是 FollowMe，但標籤上完全沒有價格數字。
{"model": "從標籤讀取", "price": null}
```

# 第三部分：型號相關知識

## 1. 型號表（型號表.txt）

### FollowMe 系列（6 個正式名稱）

- `FollowMe M5 27"`
- `FollowMe M5 32"`
- `FollowMe M7 32"`
- `FollowMe Pro M7 32"`
- `FollowMe M7 43"`
- `FollowMe Pro M7 43"`
- 已確認是 FollowMe、但照片無法分出 M5／M7／Pro／尺寸時，保留 `FollowMe 型號未細分`，不可猜測。

### 型號格式規則

- 一般螢幕：`S/C/F + 2位數字 + 1位英文 + 後續字元`
- 例如：S32DM703UC、S27CG552EC、F24T350FHC

## 2. ModelMatcher 知識（model_matching.py）

### v16.80 Size Gatekeeper

- 防止跨尺寸幻覺（S27 不會配對到 S32 型號）

### v18.41 Greedy Regex Extraction

- 處理雜訊輸入（如 `24SAMSUNG S24F532EAC`）
- 用正則提取：`([SFC][0-9]{2}[A-Z0-9]+)`

### 現行安全校正

- 官網完整碼只移除開頭 `L` 與結尾 `XZW`，中間與尾碼不得任意截短。
- 先做完整型號精確比對，再做唯一的尾碼補全。
- 近似校正只允許同尺寸、同系列且唯一的有限候選；多個候選時必須保留人工確認，不得用低門檻模糊比對硬選一款。
- 例如 `LS27HG806EFXZW` 正規化為 `S27HG806EF`，不可變成較短或不存在的型號。

# 第五部分：FollowMe 判斷規則

## 視覺特徵（必須同時符合）

1. ✅ 白色圓盤底座放在地上（直徑約 40-50 公分）
2. ✅ 白色垂直立柱從底座向上延伸
3. ✅ 螢幕安裝在立柱頂端

## FollowMe 不受遠景規則影響！

- 即使背景有其他品牌 → 還是 FollowMe 單機！
- 即使拍攝角度是斜的 → 還是 FollowMe 單機！
- 即使在走道上拍的 → 還是 FollowMe 單機！

## ⛔ 這些絕對不是 FollowMe

- 螢幕放在桌上、增高架上 → 不是 FollowMe
- M7/M5 智慧螢幕但沒有落地支架 → 不是 FollowMe

## FollowMe 型號判斷

- 必須先確認同一台螢幕具有 FollowMe 實機結構或附著標示；旁邊文宣不能代替實機證據。
- 再讀同一台實機或附著牌面的 `M5／M7`、`27／32／43`、`Pro`，面板 SKU 只用來核對系列與尺寸。
- `S32FM703UC`、`S43FM703UC` 都可能出現在一般版或 Pro 套裝；只有明確看到同機 `Pro` 才能選 Pro。
- 43 吋不等於 Pro，價格也不代表型號。
- 所有 FollowMe 都是 Smart 系列，不需要 OSD 畫面。
- 證據不足時輸出 `FollowMe 型號未細分`，不可用價格、尺寸或猜測補齊。

# 第六部分：遠景判斷規則

## 遠景判定條件（符合任一）

1. 斜角/廣角拍攝：畫面包含整排螢幕展示架
2. 多品牌區域：同時看到 2 個以上品牌大招牌
3. 無主體螢幕：沒有哪一台螢幕是「畫面主角」
4. 走道/通道視角：站在走道上拍攝整個展示區

## 核心判斷

「攝影師在拍什麼？」

- 拍「整個賣場區域」→ 遠景
- 拍「某一台螢幕」→ 單機

## ⛔ 遠景陷阱

- 即使能讀到某張標籤上的價格，但整體是拍賣場全景 → 還是遠景！
- **「能讀到價格」不代表就是單機！要看拍攝主題！**

# 第八部分：核心教訓總結

1. **OCR ≠ 創意生成**：temperature 必須低（0.1）
2. **原圖 ≠ 重編碼**：直接讀 bytes，不要用 PIL 重新存檔
3. **範例會被學習**：Few-shot 中的數值會影響模型輸出
4. **慢就是快**：讓模型「一個字一個字讀」比「快速掃描」準確
5. **測試要多次**：單次測試不可靠，至少跑 5 次確認穩定性
6. **FollowMe 最優先**：必須在遠景判斷之前先檢查
7. **型號表是唯一真理**：不要編造型號，查型號表！
8. **用戶指示 > Copilot 判斷**：用戶說什麼就做什麼，不要自作聰明！
